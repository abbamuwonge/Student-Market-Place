# CampusMart Mobile Application

## 1. Overview

CampusMart is a student marketplace mobile application designed to help university students buy and sell items such as textbooks, electronics, and school supplies.

The `app/` directory is intended to contain the mobile application frontend, which will be developed using Flutter and Dart.

## 2. Planned Features

- **User Registration and Login:** Allow students to create accounts and sign in.
- **Browse Items:** Display available items for sale.
- **Search and Filter:** Help users find items by name or category.
- **Item Details:** Show item descriptions, prices, conditions, and seller information.
- **Post Items:** Allow users to list items for sale.
- **Categories:** Organize items into relevant groups.
- **Favorites:** Allow users to save items they are interested in.
- **Messaging:** Support communication between buyers and sellers.
- **Orders:** Display order information and status.
- **User Profiles:** Allow users to manage their account information.

## 3. Technologies

- Flutter
- Dart
- Visual Studio Code
- Android Studio

The mobile application will communicate with the backend through API endpoints. Authentication, data exchange, and database operations will follow the agreed system design.
